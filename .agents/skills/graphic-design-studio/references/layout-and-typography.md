# Layout and typography

## Visual hierarchy

Use the supplied reference as the authority when the user requests a match. Preserve its composition zones, relative scale, reading path, visual density and relationship between artwork and type. Do not impose a minimalist grid on an ornate festival reference.

## Font priority

1. Reference display typography when a visual reference is supplied and the user wants its style.
2. Exact reference font if identified, available and licensed.
3. Closest suitable font plus deliberate effects when the reference uses custom lettering.
4. Brand-kit fonts for supporting text and as the default when no reference typography is supplied.

For dimensional display lettering, reproduce the reference's actual characteristics: gradient, metallic finish, highlights, bevel, multiple outlines, extrusion, shadow, flourishes and letterform weight. Effects must be controlled and coherent, not applied indiscriminately.

## Multilingual typography

Keep user copy verbatim. Verify glyph coverage, conjuncts, chillu letters, vowel signs, combining marks and shaping. Never split a word or detach a diacritic. If the chosen image generator cannot reliably render the script, reserve a clean text area and add exact copy in a finishing renderer.

## Exact copy

Treat names, dates, weekdays, times, venue, URLs and Malayalam text as locked strings. Do not translate, paraphrase, abbreviate or invent. Compare final rendered copy character-by-character with the approved brief.

## Composition details

Avoid generic cards, panels and badges unless they belong to the reference or improve the hierarchy. Preserve ornament and layering when requested. Maintain contrast, safe margins and legibility at the intended viewing size.
