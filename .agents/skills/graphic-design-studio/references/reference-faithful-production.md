# Reference fidelity and asset integrity

## Roles

A reference may control style, composition, exact subject assets, content, or several roles. Record each role separately. Do not confuse a style reference with a source asset.

## Logo lock

Use the exact approved logo file. Preserve artwork, lettering, colour, transparency and aspect ratio. Only uniform scaling and positioning are allowed unless the user explicitly authorizes a change. Never redraw, trace, retype, regenerate, recolour, distort or crop destructively. If the generator alters the logo, replace it with the original file in a finishing layer. No invented emblem or wordmark.

## Exact subjects

Use the exact uploaded person, saint, church, building, product or mascot as the source of truth. Preserve defining features and identity. Do not substitute generic lookalikes. Image generation may integrate the asset artistically but can reinterpret it; inspect the result. If identity is distorted, regenerate or use a careful compositing workflow.

## Integration, not cut-and-paste

The desired result is one coherent artwork. Match lighting direction, colour temperature, perspective, scale, depth, contrast, atmosphere and overlap. Use foreground occlusion and contact shadows only when motivated by the scene. Avoid white rectangles, arbitrary oval mats, crude polygon masks, visible sticker edges, generic glow outlines and floating subjects.

If a clean transparent cutout is not achievable, keep the complete source image in an intentional photo treatment or regenerate the composition with the image as a reference. Do not erase white robes, smoke, halo details, hair, chains, foliage or fine architecture with destructive thresholding.

## Reference fidelity

When the user asks to match a reference, compare layout, hierarchy, type treatment, palette, background, texture, density, decoration, subject placement and depth. Replace only the elements the user asked to replace. A design that merely contains the right objects but looks like a different genre is not reference-faithful.

## Generation and finishing

Use image generation for the integrated scene when suitable. Use exact source files for final logo placement and editable typography for precision. Do not claim the generated model preserved a file pixel-for-pixel unless the final file was placed unchanged and verified.
