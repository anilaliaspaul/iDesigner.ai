# Layout and Typography

The supplied reference controls display typography and composition when the user asks to follow it. Reproduce its letterform character and effects with the closest available font and carefully built vector/text styling. Brand-kit fonts are the default only when there is no reference typography direction; they remain useful for supporting copy.

Preserve the reference's visual density and ornament. Do not force minimalism or generic cards. Keep exact user wording intact. Verify Malayalam glyph coverage, conjunct shaping, vowel signs, chillu letters, combining marks and line breaks in the actual output. If the generator cannot render text reliably, finish it in an editable renderer.
