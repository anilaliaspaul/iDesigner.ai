# Iteration Manager

Translate feedback into explicit change requests. Identify locked/approved elements and preserve them. Change only requested items unless the user asks for a full redesign. Diagnose the cause of a failure before regenerating. Keep immutable versions v01, v02, etc.; record prompt changes, asset changes, feedback and QA. Retrieve and inspect a fresh preview after each meaningful change. Never mark a design approved until the user explicitly approves it.
