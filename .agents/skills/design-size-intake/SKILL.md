# Design Size Intake

Run this stage after brand selection/kit review and poster requirement intake, not before.

1. Reuse dimensions and platform already supplied in the conversation or project.
2. Ask for intended platform/use first when unclear (Instagram feed, story, WhatsApp, print poster, flyer, banner, etc.).
3. If the user knows exact dimensions, record width, height, unit, orientation, bleed and safe margins.
4. If the user does not know, recommend a suitable current standard for the chosen platform/use, state exact dimensions and ask for confirmation. Do not silently impose a canvas.
5. For print, confirm physical size, bleed and resolution (normally 300 DPI for small-format print); aspect ratio alone does not make an image print-ready.
6. For digital, record pixel dimensions, platform and safe zones.
7. Include agreed dimensions in production prompts, finishing/export settings and independent QA. Verify the actual export.

Ask one concise question at a time. Never ask again for dimensions already supplied. The user may authorize iDesigner.ai to choose the best standard size.
