# Brand Management Workflow

1. Ask which brand the design is for.
2. Search the active workspace brand registry by normalized slug and saved brand.json name.
3. If found, confirm whether to use or update it, then load the kit.
4. If not found, say no saved kit exists and ask permission before creating one.
5. After consent, collect official name, address, recurring branding text, tagline, logo and website. If no website exists, ask for recent posters/designs. Allow optional fields to be skipped.
6. Create the brand folder from the generic template. Save brand.json, design-readme.md, palette, typography inventory, exact logos, references and approved photography.
7. Mark sources and confidence; keep the kit proposed until the user approves it.
8. Re-read the saved kit, validate it and confirm the brand loaded into the design workflow.
9. Keep all client-specific assets in the active workspace. Never ship a default brand or commit private client assets to the public plugin repository.
