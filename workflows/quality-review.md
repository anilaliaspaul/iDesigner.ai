# Quality Review

This workflow is orchestrated by the main studio skill and executed by the independent quality-reviewer role. Inspect the actual artwork and exported file.

## Mandatory review order
1. **Message:** identify communication type, intended audience, intended response and single main message.
2. **Copy semantics:** read all text in order; check sentence choice, completeness, grammar, spelling, punctuation, repetition and whether every sentence adds value.
3. **Facts:** verify names, dates, weekdays, times, venue, address, URL, phone, prices and contact details against user-approved source text.
4. **Mobile readability:** inspect at actual phone feed/story size and thumbnail. Check headline, essential details, CTA, contrast, crop and safe zones.
5. **Typography and language:** verify font choice, hierarchy, size, spacing, shaping, script support, line breaks and readability, including Malayalam conjuncts/chillu/vowel signs where relevant.
6. **Accessibility:** verify contrast, readable type size, clear reading order and that meaning is not conveyed by colour alone.
7. **Brand and reference:** verify selected brand name, recurring text, logo source/fidelity, palette, fonts, asset identity and reference fidelity or selected concept.
8. **Visual and technical craft:** inspect object integrity, anatomy, architecture, perspective, lighting, artifacts, margins, dimensions, resolution, bleed, format and export integrity.

Return PASS / FAIL / UNKNOWN with evidence and concrete fixes. UNKNOWN is not PASS. Preserve user-approved copy. A visually attractive design must fail if its communication or facts fail.

## Rework loop
On FAIL, send the precise defect list to the graphic designer. Preserve passing elements, revise only defects, then inspect the new export. Repeat until PASS or report a genuine blocker. Only after PASS can the artwork be shown to the user for approval.
