# Creative Direction Workflow

## Path A — reference supplied
1. Analyse the reference composition, hierarchy, typography, palette, lighting, texture, depth and visual density.
2. Identify every meaningful object and ask for exact replacement photos/assets where the design must show the user's real brand, people, place, product or other identity-critical subject.
3. If an exact image is unavailable, ask what should replace it; if the user is unsure, suggest 2–3 context-appropriate alternatives.
4. Ask whether to retain brand typography or use the reference's typography treatment. Preserve exact approved copy unless the user explicitly requests reference wording.
5. Recreate the reference faithfully and integrate the saved brand identity deliberately. Do not force the no-reference concept exercise.

## Path B — no reference
1. Research the broad category, region, audience and occasion using broad search, campaign galleries, portfolios and available visual trend sources.
2. Synthesize the wider landscape and inspect a representative set of strong examples. Do not claim to have individually reviewed thousands unless verifiable.
3. Record 3–5 useful patterns, crowded visual territory, differentiation opportunities and an OFF-LIMITS cliché list.
4. Generate ten distinct directions, score them and present the best three for user selection.
5. Produce only after concept selection or explicit delegation.

Never copy competitor logos, artwork, trade dress or distinctive layouts.
