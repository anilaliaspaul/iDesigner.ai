# Brand-first reference and output intake

This workflow follows brand discovery; do not ask for poster details or dimensions before the brand is identified and its saved kit is loaded/created.

1. **Brand:** ask which brand and search the active workspace registry. If missing, ask permission before creating a kit.
2. **Brief:** ask what the user wants to design and collect exact copy, audience, purpose and factual details.
3. **Output:** ask platform and size unless supplied. Recommend a standard only when needed and confirm before fixed-size production.
4. **Reference:** ask whether a reference design exists. If attached, inspect it before concepting.
5. **Reference objects:** identify meaningful objects and request exact user assets for identity-critical replacements. Resolve unavailable objects with user-selected or approved suggested alternatives.
6. **Typography:** ask whether to retain brand typography or follow the reference's typography treatment. Do not copy reference wording unless requested.
7. **No reference:** proceed to broad category research, cliché avoidance and ten-to-three concept selection.

Ask one stage at a time. Reuse known information. Do not confuse a reference image with an exact subject asset.
