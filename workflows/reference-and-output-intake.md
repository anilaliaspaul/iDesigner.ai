# Reference and output intake workflow

This workflow is mandatory at the start of each new design request.

1. **Output:** ask for platform and exact dimensions unless supplied in the current request. Record the size in the project brief. Never infer it from another project.
2. **Reference:** ask whether the user has a reference image/design. It is optional. If supplied, inspect it before concepting.
3. **Analyse:** review layout, hierarchy, typography, palette, contrast, whitespace, imagery, texture, density and tone. Summarize what to retain, improve and avoid.
4. **Prompt review:** if the user supplied a prompt, compare it with the reference, brand rules and brief. Resolve contradictions, tighten vague instructions and protect exact copy. Ask only about material conflicts or missing facts.
5. **No reference:** proceed with an original concept grounded in the selected brand and purpose. Do not repeatedly request a reference.
6. **Approval:** present a concise creative direction or 2–3 distinct concepts according to the main studio workflow before production, unless the user explicitly asks to proceed directly.

Do not confuse a reference image with permission to copy it exactly. Follow the user's stated intent and applicable brand/copyright constraints.

## Additional rules learned from coordinated print-card production

7. **Classify every image by role.** Record whether each upload is a style reference, front-page reference, exact background photograph, logo, subject asset or text source. Do not treat a photo explicitly requested as a background as permission to generate a similar replacement.
8. **Recover copy from references when needed.** If the user supplies a reference image but no separate wording, transcribe its visible text as the default copy. Flag uncertain text for confirmation; do not invent or fill gaps.
9. **Proofread before designing.** When proofreading is requested, correct grammar, punctuation, spelling and flow without changing meaning or facts. Present the complete revised copy for approval before placing it into the artwork when wording has changed. Lock the approved copy for all subsequent versions.
10. **Keep exact text out of image generation.** Use image generation for the visual background/artwork only. Typeset all final wording separately as editable text or through a precise finishing workflow. Compare the finished design against the approved copy line by line.
11. **Coordinate front and back.** When one side of a card is supplied as the reference for the other, match palette, border, typography character, seasonal mood, ornament style, dimensions, orientation and print setup. Keep the back less decorative if needed for legibility, but visibly part of the same set.
12. **Respect supplied photo backgrounds.** If the user asks to use an uploaded church/building/photo as the background, place that exact source image. Do not substitute generated architecture or a lookalike. Preserve defining features and disclose significant cropping.
13. **Print sizing.** For supplied physical dimensions, lock the size. For small print, target 300 DPI; calculate pixels from the physical dimensions (10 × 15 cm ≈ 1181 × 1772 px at 300 DPI). Check safe margins and printer-specific bleed separately.
14. **Long-copy readability.** Fit the copy through layout, line length, spacing and hierarchy before reducing font size. If it remains crowded, recommend concise copy or a larger format instead of silently dropping content or making text too small.
15. **Skip redundant intake.** When the user already supplied the content, reference, size and clear instruction to create, proceed with one considered design direction. Ask only for genuinely missing essentials; do not repeat questions or force concept selection.
