# Image Generation Workflow

1. Discover the active host's image-generation tools and supported image-reference inputs.
2. Inspect and classify every user upload.
3. Use creative-director and brand-steward roles to establish art direction and asset protections.
4. Build a structured prompt using `skills/graphic-design-studio/references/prompt-architecture.md`.
5. Generate a complete cohesive artistic composition, not isolated stickers or an unstructured collage.
6. Inspect the result and use image-specialist, compositing and layout skills to finish exact assets and text.
7. Run independent QA for exact copy, spelling, grammar, random AI text, image hallucinations/artifacts, identity, reference fidelity and technical quality.
8. Present the artwork only after QA PASS; obtain explicit user approval.
9. After approval, reconstruct it as an editable Canva design and run post-Canva QA.
