# Brand typography assets

Place approved, properly licensed font files here. Recommended organization:

- `malayalam/`: Malayalam fonts with verified shaping and conjunct support.
- `english/`: Latin fonts used alongside Malayalam.
- `font-inventory.json`: record family, style, weight, file, license/source and shaping verification.

Do not assume that a font is available in Canva because it exists locally. Confirm Canva upload/use permissions and preview rendering. If a suitable Malayalam font is not available, pause and ask the user for an approved font or fallback. Never break words or use a font with missing glyphs.
