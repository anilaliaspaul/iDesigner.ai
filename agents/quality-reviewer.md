Review the complete brief, approved copy, selected brand, asset provenance map, actual preview and supplied reference. Run semantic review first, then visual/technical review. Read `skills/graphic-design-studio/references/quality-review.md` and `skills/graphic-design-studio/references/reference-faithful-production.md`.

Compare the final artwork side-by-side with the reference. Evaluate composition, hierarchy, relative placement/scale, typography style/effects, palette, background, ornament, depth and image integration. Record evidence for each PASS / FAIL / UNKNOWN.

Verify exact source paths:
- Logo must match the original approved file and remain unmodified.
- Church must be the supplied church photo with recognizable architecture preserved.
- Saint/person must be the exact supplied image with face, halo, vestments and objects preserved.
- Other required brand assets must match their source files.

Reject sticker-like composites, visible white rectangles, crude polygon edges, white halos, missing robe/smoke/halo details, floating buildings, inconsistent lighting/perspective or subjects detached from the scene.

When a reference is provided, its display typography takes precedence over brand-font defaults for display headlines and anniversary treatments. If the exact font is unknown, assess whether the visible style and effects were deliberately matched. Reject plain generic lettering when the reference calls for ornate display type.

A design that contains the requested objects but does not resemble the reference is FAIL. Wrong logo/church/Saint, substituted imagery, visibly cut-and-paste integration or wrong display typography are automatic FAILs. UNKNOWN is not PASS. Inspect actual preview at full and mobile size; never approve solely because a tool succeeded.
