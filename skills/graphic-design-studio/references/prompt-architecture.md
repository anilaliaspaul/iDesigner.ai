# Production prompt architecture

Translate the approved brand kit, brief, research and selected concept into a production-ready prompt. The user should not need to author it.

## A. Reference and asset map
For each image record filename/reference and role: style reference, composition reference, exact logo, exact subject, background/photo, content reference or supporting asset. State what transfers and what must remain unchanged.

## B. Brand and research
Include brand name, approved/provisional status, palette/type rules, logo handling, recurring brand text, audience and tone. Include 3–5 research insights, the OFF-LIMITS cliché list and the chosen differentiation opportunity. Never copy competitor artwork or trade dress.

## C. Deliverable
Record purpose, platform, exact dimensions, orientation, print/digital medium, resolution, bleed and safe areas. Reuse confirmed details; recommend and confirm missing dimensions.

## D. Art direction and composition
Define visual genre, emotional tone, focal point, hierarchy, reading path, zones, relative scale, overlaps, negative space, foreground/middle/background, lighting, palette, texture and depth.

## E. Typography and exact copy
Specify English/Malayalam font roles, script shaping requirements, display treatment, exact line breaks and a locked verbatim copy block. No added slogans, captions or pseudo-text. If image generation cannot render the script reliably, leave clean space and finish text separately.

## F. Constraints and acceptance
List exact assets, protected identity features, prohibited substitutions, cliché blacklist, negative constraints and observable QA acceptance tests. Do not promise pixel-perfect preservation from image generation alone.
