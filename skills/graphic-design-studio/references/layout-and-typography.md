# Layout, typography and multilingual copy integrity

## Reference-aware visual standard
A supplied reference can be a visual specification, not merely inspiration. When the user asks for the same style, match composition, hierarchy, density, typography treatment, colour relationships, texture, lighting, ornament and visual tone. Do not impose the studio's minimalist default on an ornate or maximalist reference. Retain only the elements the user asks to change.

Before layout, map composition zones, relative scale, focal point, reading path, display type style/effects, background texture, palette, decoration, image placement, overlap, depth and lighting.

## Typography priority
1. If a visual reference is supplied and the user asks to follow its style, its display typography is the primary authority for titles, festival names, anniversary numerals and ribbons.
2. Use the exact reference font if identified, available and licensed.
3. If unknown or custom lettering, identify visible characteristics (script, weight, width, contrast, terminals, ornament, outline, bevel, extrusion, gradient, shadow and dimensionality) and reproduce the style with the closest suitable font plus deliberate vector/text effects.
4. Use brand-kit fonts for supporting copy and general brand typography. Use brand display fonts as the default only when no typography reference is supplied or the user explicitly asks for them.
5. If no font can approximate the requested style, explain the limitation before substituting a generic face.

## Professional composition
- Use one focal point and a clear reading path, but let visual density follow the supplied reference.
- Rich festival posters may use layered foliage, illustrative subjects, ornate badges, frames and dimensional typography when the reference does.
- Avoid random decoration, fake labels, arbitrary icons, filler microcopy and generic AI flourishes.

## Multilingual copy integrity
- Preserve exact Malayalam and English characters, spelling, punctuation, word order and language.
- Never split words or detach Malayalam vowel signs/diacritics.
- Verify glyph coverage, conjunct shaping and actual preview/export.
- Do not use image generation to render text. Keep copy editable as text/vector typography.
- Do not replace elaborate reference lettering with a plain brand body font.
- Change layout or ask for approved shorter wording if copy does not fit; never shorten it yourself.
