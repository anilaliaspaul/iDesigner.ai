# Independent Quality Assurance — mandatory approval gate

Inspect the actual generated artwork and final export, not only the prompt or tool-success message. Return PASS / FAIL / UNKNOWN with evidence. UNKNOWN is never PASS.

## 1. Copy and language
Compare all visible wording with the approved copy/fact sheet. Check sentence selection, message clarity, grammar, spelling, punctuation, capitalization, sentence completeness, names, dates, weekday, time, venue, URL, price and contact. Use OCR as a helper, then visually verify. Flag random words, pseudo-text, fake labels, hallucinated dates/logos and watermarks. Any unrequested text is FAIL. User copy is locked; propose corrections and obtain approval before changing it. For Malayalam, inspect glyph coverage, shaping, conjuncts, chillu letters, vowel signs, combining marks, punctuation and line wrapping.

## 2. Mobile readability and accessibility
Inspect at actual intended phone feed/story size and thumbnail size, not only full-screen zoom. Confirm headline, essential details and CTA can be read without zooming. Check platform crop and safe zones, text/background contrast, readable type size, clear reading order, plain-language clarity and that information is not conveyed by colour alone. Ensure key facts are not hidden inside decorative imagery.

## 3. Image and identity
Inspect full resolution and target size. Check faces/anatomy, architecture, products, symbols, duplicated objects, perspective, lighting, colour temperature, shadows, edges, halos, masks, texture seams and AI artifacts. Verify supplied identity assets remain faithful. Wrong or materially distorted required assets are FAIL.

## 4. Reference and design craft
Compare side-by-side for composition, hierarchy, focal point, scale, reading path, type character/effects, palette, background, texture, depth, ornament and density. Verify every mapped object is correct and any missing replacement asset was resolved with the user. Check balance, contrast, legibility, margins, clipping, overlap, crop and output dimensions. Do not impose minimalism on a maximalist reference.

## 5. Brand and originality
Verify the selected brand kit matches the requested brand, with correct approved/provisional status, source logo when used, palette, typography, recurring copy and asset provenance. Check no other brand's identity has leaked into the artwork. Compare the final artwork with the project's research note and OFF-LIMITS cliché list. A listed cliché without user approval is FAIL. Do not copy a competitor's distinctive layout, artwork, logo or trade dress. Confirm the chosen concept remains recognizably distinct from the researched examples.

## 6. Export and editability
Inspect the actual exported file at full size and intended viewing size. Verify format, pixel/physical dimensions, aspect ratio, resolution, bleed/safe areas and file integrity. For editable renderer/Canva handoff, compare preview against approved artwork and accurately report editable versus flattened elements.

## Decision and rework loop
Any incorrect fact, unapproved text, serious spelling/grammar error, unreadable mobile text, accessibility failure, wrong brand/logo/subject, identity distortion, serious artifact, broken layout, failed reference criterion or unapproved cliché is FAIL. Return a precise defect list. The graphic designer must preserve passing elements, fix only failed items and resubmit the actual new export. Repeat independent QA until PASS or report a genuine blocker. Only a complete PASS can be presented for user approval. User approval is a separate gate. Never claim a QA PASS without inspecting the artifact.
