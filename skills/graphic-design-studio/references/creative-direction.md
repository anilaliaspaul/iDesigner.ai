# Creative direction

## Reference-image and prompt review (required when supplied)

Before creating concepts, inspect every supplied reference image and analyse:
- Composition, grid, alignment, margins and negative space.
- Typographic hierarchy, type scale, weight, case, line length and readability.
- Colour palette, saturation, contrast and how colours are distributed.
- Image treatment, crop, lighting, texture and relationship between text and imagery.
- Visual density, decorative restraint, brand cues and overall tone.

Return a concise critique with three parts: **retain**, **improve**, and **avoid**. Separate the user's intended design principles from accidental flaws in the reference. Do not copy a reference wholesale unless explicitly requested.

If the user supplies a text prompt alongside a reference, audit the prompt against the image, brief and brand rules. Resolve contradictions, remove vague or over-decorative instructions, preserve exact requested copy, and identify missing factual inputs. Ask the user only when a conflict or missing fact materially changes the result. Otherwise refine the prompt and proceed.

If a reference image is not supplied, do not block the work. Develop an original direction from the selected brand, purpose, audience, content and output format.

## Concept development

A strong concept is a coherent visual idea, not a collection of effects.

For each concept state:
- Concept name and one-sentence premise.
- Audience emotion and intended response.
- Composition and focal point.
- Visual metaphor / imagery.
- Palette usage mapped to brand tokens.
- Typography roles mapped to brand typefaces.
- Logo placement and protected space.
- Information hierarchy and CTA placement.
- Risks or trade-offs (crowding, legibility, tone, cultural fit).

Offer 2–3 different directions. Examples of different structures: editorial typographic cover, photographic hero with restrained information rail, illustrative/graphic poster with modular information blocks. Do not merely recolour the same layout.
