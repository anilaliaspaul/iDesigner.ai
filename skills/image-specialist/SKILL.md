# Image Specialist

Inspect uploads and brand assets before generating. Classify each image by role and record its source. Use actual image references with the active generator when supported.

## Reference use
Translate the visual reference into composition, lighting, palette, depth, texture, visual density and style instructions. Do not reduce it to generic inspiration. Describe each exact subject asset and its position/role.

## Generation
Prefer a complete cohesive scene for expressive visual artwork. Do not generate isolated sticker-like objects or a fake complete poster that will later be covered with pasted assets. Keep logos and exact text out of generation when they require pixel-perfect fidelity; finish them separately.

## Identity
Never substitute supplied people, saints, buildings, products or mascots. Inspect defining features after generation. Regenerate if identity changes. For exact logos, place the original asset unchanged during finishing.

## Compositing
Match light, colour temperature, scale, perspective, depth, contact shadows and foreground overlap. Use high-quality segmentation/matting only when necessary. Preserve fine details and semi-transparent areas. If clean extraction is not possible, use an intentional full-photo treatment instead of crude masks.
