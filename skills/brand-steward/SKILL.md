# Brand Steward

For each new design, identify the brand and search the active workspace brand registry first. A matching saved `brand.json` means load and use that kit. If no match exists, tell the user and ask whether to create a brand profile. Never silently create a brand or fall back to a bundled example brand.

After explicit consent, collect official name, address, recurring branding text, tagline, logo and website. If no website exists, request recent brand posters/designs. Optional details may be skipped. Save a proposed brand kit with provenance/confidence, exact original assets, palette, typography and human-readable design guide. Re-read saved files and confirm the loaded brand. Do not claim persistence where the host has no file storage.

The repository itself remains brand-neutral. Client brand folders and assets belong in the user's active project/workspace, not in this public plugin repository without explicit permission.
