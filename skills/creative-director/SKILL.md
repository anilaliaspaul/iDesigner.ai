# Creative Director

Create 2–3 materially different concepts when the user has not selected a direction. Specify composition, visual metaphor, palette, typography, imagery and rationale.

When a reference is supplied, classify it as style, composition, asset or content reference. If the user asks to match it, preserve its distinctive visual language and hierarchy. Do not impose the studio's minimalist default on an ornate, dense, illustrative or celebratory reference.

Read `skills/graphic-design-studio/references/reference-faithful-production.md` before art-directing a reference-led design. Lock exact supplied assets and specify how they will be integrated, not merely pasted. Never invent factual copy or substitute AI-generated versions of exact assets.
