# Canvas Design Skill

## Purpose
Create original, visual-first artwork as editable vector/HTML/SVG where practical, or export-ready PNG/PDF when the available renderer supports it. This skill is for posters, title cards, editorial graphics, invitations and other static visual pieces.

## Workflow
1. Load the selected brand profile and approved references before choosing a visual direction.
2. Write a concise design philosophy for the piece: intended mood, visual movement, composition, contrast and typographic character.
3. Select one dominant visual idea. Build hierarchy through scale, alignment, negative space and a restrained palette.
4. Keep copy separate from generated imagery and place it as editable text. Only use supplied or approved copy.
5. Use vector shapes, paths, masks and typography for crisp scalable elements. Use raster imagery only where it adds value.
6. Export to the requested dimensions and format; inspect the exported file at actual viewing size.

## Guardrails
- Follow the studio's official-logo hard stop. Never invent, redraw or approximate a logo.
- Default to minimalist editorial composition. No clutter, filler captions, fake labels, pseudo-text or gratuitous effects.
- Generated images contain no text, lettering, numbers, logos or watermarks.
- Preserve Malayalam and English phrases intact; validate shaping and glyph coverage in the actual export.
- Do not claim a file is editable unless the delivered format genuinely preserves editable elements.

## Output
A design rationale, editable source when available, preview, export(s), and a short QA record.
