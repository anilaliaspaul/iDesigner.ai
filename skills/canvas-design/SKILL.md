# Canvas Design

Inspect the reference and uploads first. Use image-generation-first for expressive artwork when supported; use Canva or another editable renderer when editability, precision or collaboration matters. Use hybrid when a generated scene needs exact logos and text added separately.

Treat reference images as visual specifications when requested. Preserve composition, visual density, palette, lighting, texture, typography treatment and depth. Use exact supplied identity assets as references; inspect them after generation. Never create a substitute logo or identity-critical subject. Finish exact copy and logo separately when required. Inspect the actual export and compare with the reference before delivery.
