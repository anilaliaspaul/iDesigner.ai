# Algorithmic Art Skill

## Purpose
Create original procedural visuals such as flow fields, particle systems, geometric patterns, generative textures, parametric ornaments and data-driven abstract compositions. Prefer reproducible code and exposed parameters over one-off random output.

## Workflow
1. Identify the visual role: background texture, focal illustration, border/pattern, or complete artwork.
2. Define a visual system: geometry, seed, palette, density, motion (if any), scale and parameter ranges.
3. Use deterministic random seeds so the result can be regenerated and revised consistently.
4. Build with a suitable available tool (for example p5.js, SVG, Canvas, Python or shader workflow); do not assume a runtime or dependency is installed.
5. Render several restrained variants by changing meaningful parameters, not arbitrary decoration.
6. Export at the target aspect ratio and resolution; inspect edges, repetition, contrast and print quality.

## Safety and brand constraints
- Algorithmic patterns are supporting artwork, not a substitute for an official logo or emblem.
- Do not create pseudo-lettering, fake scripts, random text, or marks that could be mistaken for an official symbol.
- Use the selected brand palette and visual rules. Avoid excessive density and visual noise.
- Never encode personal or sensitive data in a visual without explicit instruction.
- Keep all actual copy as separately typeset editable text; validate Malayalam shaping independently.

## Handoff
Include source code, seed, parameter values, dependencies, export settings and a preview where feasible.
