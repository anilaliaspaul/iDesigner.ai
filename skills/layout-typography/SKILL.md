# Layout Typography

Read `skills/graphic-design-studio/references/reference-faithful-production.md` before layout when a reference is supplied.

- When a reference is intended to guide the design, its display typography takes priority for titles, festival names, anniversary numerals and ribbons.
- Use the exact reference font if identified and available. If unknown/custom, reproduce its visible style with the closest suitable font plus deliberate editable/vector effects: gradient, bevel, outline, extrusion, shadow and ornament.
- Use brand-kit fonts for supporting copy and as the default display system only when no reference typography is supplied or the user explicitly requests brand fonts.
- Never silently replace ornate reference lettering with a plain generic font.
- Keep copy editable and exact. Never use image generation to render Malayalam or English text.
- Verify Malayalam glyph coverage, conjunct shaping, line breaks and combining marks in the actual preview/export.
- Match reference hierarchy, relative scale, visual zones, overlap and reading path. Do not force a minimalist grid onto a richly layered reference.
