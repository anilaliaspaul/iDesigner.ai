# Changelog

## 1.4.2 — Context-aware brand asset selection

- Added explicit rules that brand photography is optional, not mandatory decoration.
- Use church/building interiors and exteriors only when the event, message or composition benefits from them.
- Choose event-relevant imagery for seasonal, youth, education and campaign designs instead of repeatedly inserting the same organization photos.
- Preserve exact uploaded logos and identity-critical photographs; never replace them with generated approximations.
- Updated all platform manifests and installation documentation to version 1.4.2.

## 1.4.0 — Brand-first design wizard

- Added staged brand selection and kit discovery before poster brief and output sizing.
- Added brand-kit fallback: existing kit → website → recent poster/logo → guided interview.
- Made logo, website, tagline and address optional; missing assets no longer block production.
- Added brand-kit provenance, confidence and approval states, with palette and original-logo retention in the active workspace.
- Added comparable-brand/audience research for new posters, including an explicit cliché blacklist.
- Added ten distinct concept routes, a scored top-three shortlist and user selection.
- Expanded English/Malayalam typography and bilingual shaping checks.
- Added QA for brand consistency, concept distinctness and cliché avoidance.
- Fixed brand-kit validation so an absent logo is informational rather than a production blocker.
- Removed client-specific sample-brand assumptions; the repository ships only a generic brand template.
- Preserved specialist skills, agents, platform adapters, reference-led production and independent QA.
