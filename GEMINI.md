# iDesigner.ai for Gemini CLI

Read `AGENTS.md` for the shared operating rules. For every design request, load `skills/graphic-design-studio/SKILL.md` and the relevant specialist skills. The canonical skills live in `skills/`; the `.agents/skills/` directory is a compatibility mirror.

Use only tools available in this Gemini CLI session. Image generation, image editing, Canva and other integrations are optional host capabilities, not guaranteed by this extension. Never claim a tool action succeeded unless the tool confirms it.
